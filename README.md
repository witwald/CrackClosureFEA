# Finite Element Analysis of Crack Closure Using Newman's Method

Newman [1][2] developed a two-dimensional finite-element computer program, tyat accounts for both plastic-plastic material behavior and changing boundary conditions associated with
crack extension and intermittent contact of the crack surfaces under cyclic loading. The Fortran implementation included an efficient technique to account for changing boundary conditions and was incorporated into the nonlinear analysis program. The program can be used to study crack extension and crack closure under constant amplitude and two-level block loading. The program can calculate crack-closure and crack-opening stresses.

[1] Newman, J. C., Jr, (1974). Finite-Element Analysis of Fatigue Crack Propagation – Including the Effects of Crack Closure. PhD Thesis, Virginia Polytechnic Institute and State University, May 1974, Blacksburg, Virginia.

[2] Newman, J. C., Jr. (1974). A Finite Element Analysis of Fatigue Crack Closure. NASA-TM-X-72005, Langley Research Center.
